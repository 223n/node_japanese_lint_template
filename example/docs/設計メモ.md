# 設計メモ

この文書は、テンプレートの検査が実際に通ることを確かめるための見本である。
文体は「である調」で、一文一行で書く。

## 構成

この見本は2つの層に分かれており、依存は一方向に流れる。

| 層 | 位置 | 責務 |
| ---- | ---- | ---- |
| 画面 | `src/ui` | 表示と入力の受け取りだけを行う |
| 中核 | `src/core` | 判定と集計を行う。表示の都合を知らない |

判定や集計を画面に書かないという方針を、語彙の検査で機械的に見る。
表示だけのために要る行には、理由を添えた断りを書く。

## 検査の対象

この見本には、次の3つの検査がかかる。

1. Markdownの書式（`markdownlint-cli2`）
1. 日本語の書き方（`textlint`）
1. 語彙の混入（`lint-vocabulary`）

いずれも `npm run lint` でまとめて実行できる。
